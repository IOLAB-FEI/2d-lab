# mmodels v1 – implementačný plán

Podľa [design dokumentu](../specs/2026-11-03-mmodels-design.md).

1. **Projekt** – Vite + Vue 3 + TS, Vuetify 3, Pinia, KaTeX, lz-string, Vitest; `npm run dev|build|test`.
2. **Jadro (`src/core`)** – typy modelu a schéma, lineárna algebra (LU, expm), zostavenie M/C/K, stavový model, simulácia (ZOH, vstup v strede kroku), symbolické rovnice (LaTeX), validácia, Modelica export, ukážkové modely. Testy proti analytike.
3. **Store** – model + história (snapshot undo/redo, autosave do localStorage), UI stav (režim, výber, čas, rýchlosť).
4. **Editor** – SVG plátno, tvary (stena, teleso, pružina, tlmič, sila), paleta s ťahaním (pointer events), porty a magnet, výber, presun, mazanie, klávesy.
5. **Simulácia a pohľady** – `useSimulation` (prepočet pri zmene), prehrávač, animácia telies, graf (bledá budúcnosť, kurzor, seek), rovnice s farbami a zvýraznením, ťahanie telesa nastavuje x₀.
6. **Ukladanie** – export/import JSON, zdieľací odkaz v `#`, Modelica `.mo` na stiahnutie.
7. **Overenie** – `npm test`, `npm run build`, ručne v prehliadači.
